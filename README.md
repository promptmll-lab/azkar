# حصن المسلم — أذكار الصباح والمساء

موقع ثابت لأذكار الصباح والمساء الصحيحة بمصادرها، بخط ثمانية، مع مسبحة لكل ذكر، وتكبير خط ووضع ليلي/نهاري.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى فرع `main` في الجذر (`index.html` في الأعلى).
2. من Settings > Pages اختر Deploy from a branch ثم `main` و `/ (root)`.
3. الرابط سيكون: `https://USERNAME.github.io/REPO/`
